### This is a repository containing JavaScript ExtendScripts to automate workflows in Adobe AfterEffects.


- `Main.jsx`: Opens a palette UI for launching the automation scripts and selected built-in After Effects commands.
- `align_footage.jsx`: Imports selected video files, shuffles them, scales them into a 4K composition, and places the resulting comp into the active composition.
- `digit.jsx`: Creates an animated text layer for entered text or common unit conversions with formatted numbers and a drop shadow.
- `fade-in.jsx`: Adds a one-second opacity fade-in to each selected layer.
- `fade-out.jsx`: Adds a one-second opacity fade-out from the current time to each selected layer.
- `flags.jsx`: Imports a flag comparison project, replaces five flag images, updates values, and adjusts chart labels and bars.
- `insertImage.jsx`: Downloads images for a search query, imports the newest downloads, and places animated image layers into the active composition.
- `mapMarker.jsx`: Creates city marker labels, connecting paths, and downloaded city images tied to nulls in a map composition.
- `photo.jsx`: Adds a quick camera-flash opacity animation and camera sound effect to selected layers.
- `photo_text.jsx`: Creates centered animated text with a camera-flash opacity effect, drop shadow, and camera sound.
- `population.jsx`: Builds an animated population pyramid composition from a selected CSV file and inserts it into the active composition.
- `put.jsx`: Adds a random "Put" sound effect above each selected layer and enables motion blur.
- `replaceImages.jsx`: Replaces selected layer sources with imported image files chosen by the user.
- `replaceMusic.jsx`: Replaces selected audio layers with random unused tracks from category folders that match the layer names.
- `schlagschatten.jsx`: Adds a strong zero-distance drop shadow effect to each selected layer.
- `shorts.jsx`: Imports selected videos into a vertical 1080x1920 composition as short randomized muted clips.
- `text.jsx`: Applies a camera-flash opacity animation and camera sound effect to the selected layer.
